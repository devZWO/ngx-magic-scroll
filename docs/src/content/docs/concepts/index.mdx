`ngx-magic-scroll` connects stable content IDs to the route fragment and the position of a scroll container. Regions define eligible targets, URL state identifies the section, data readiness determines when initial restoration can run, and position preservation handles later changes.

Read the concepts in order for the full model, or choose the topic relevant to your application.
